`procview` — консольная программа для Linux, которая получает PID процесса и выводит информацию о нём из файловой системы `/proc`.

## Возможности

Программа отображает:

* PID процесса;
* имя процесса;
* состояние процесса;
* PID родительского процесса;
* командную строку;
* количество открытых файловых дескрипторов.

## Требования

Для работы программы необходимы:

* Linux;
* GCC или Clang;
* GNU Make.

## Сборка

Обычная сборка:

```bash
make
```

После успешной сборки исполняемый файл находится здесь:

```text
bin/procview
```

Debug-сборка с AddressSanitizer и UndefinedBehaviorSanitizer:

```bash
make debug
```

Release-сборка с оптимизацией:

```bash
make release
```

Очистка результатов сборки:

```bash
make clean
```

## Запуск

Синтаксис:

```bash
./bin/procview <PID>
```

Пример для PID текущего shell:

```bash
./bin/procview $$
```

Получить PID текущего shell отдельно можно командой:

```bash
echo $$
```

Пример для процесса с PID 1:

```bash
./bin/procview 1
```

## Используемые файлы `/proc`

Для получения информации используются следующие пути:

```text
/proc/<pid>/status
/proc/<pid>/cmdline
/proc/<pid>/fd
```

### `/proc/<pid>/status`

Файл читается построчно. Из него извлекаются поля:

```text
Name:
State:
Pid:
PPid:
```

### `/proc/<pid>/cmdline`

Файл содержит аргументы командной строки, разделённые нулевыми байтами `'\0'`.

Байты читаются последовательно и собираются в динамическую строку. Нулевые байты заменяются пробелами.

Если `cmdline` пуст, выводится:

```text
Command line: [not available]
```

### `/proc/<pid>/fd`

Каталог содержит записи открытых файловых дескрипторов процесса.

При подсчёте пропускаются специальные записи:

```text
.
..
```

Остальные записи учитываются как открытые файловые дескрипторы.

Содержимое символических ссылок внутри каталога `/proc/<pid>/fd` программой не читается.

## Ограничения

Процесс может завершиться между моментом получения PID и чтением его файлов в `/proc`. Поэтому данные могут стать недоступными во время выполнения программы.

Доступ к некоторым процессам и их данным может зависеть от прав пользователя и настроек системы.

Количество файловых дескрипторов процесса может отличаться от ожидаемого значения, так как процесс может иметь дополнительные открытые дескрипторы.

## Коды завершения

```text
0 — программа успешно завершилась.

1 — ошибка чтения или доступа к данным процесса.

2 — некорректные аргументы командной строки или некорректный PID.
```
